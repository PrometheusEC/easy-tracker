# Contributing

Thanks for checking out Easy Tracker.

Bug reports, feature ideas, and pull requests are welcome.

## Before opening an issue

Please include:

- Your Windows version
- Whether you are running the Python source or the compiled `.exe`
- A short description of what you expected
- What actually happened
- Any useful error message or screenshot

## Pull requests

Keep changes focused and easy to review. If a change affects the CSV schema,
please mention it clearly so backward compatibility can be considered.

## Planned direction

The next major feature currently planned is a Data Analysis page for visualizing
application activity and outcomes.
