EASY TRACKER — PySide6 Edition

Why PySide6?
------------
This version uses Qt/PySide6 instead of Tkinter for:
- Better Windows-style UI
- Native-style calendar popup via QDateEdit
- Better theming and styling
- Better table behavior
- Cleaner path to a polished .exe later

Features retained
-----------------
- Company
- Country
- Date of application
- Position
- Application medium
- Status
- Last Update
- Next Follow-up
- Job URL
- Notes
- Search
- Multi-select
- Bulk delete
- Open multiple URLs
- Dark / Windows Light / Slate themes
- CSV persistence

How to run
----------
1. Extract the ZIP.
2. Double-click run_job_tracker.bat.
3. The launcher will install PySide6 automatically if needed.
4. The app will then start.

Your data is stored in:
job_applications.csv

Later, this can be packaged as a standalone Windows .exe.

Sorting
-------
Click any column header to sort ascending. Click the same header again to reverse the sort.
